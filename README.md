## 👋 Sobre mí

Soy Kerin, un chico al que le gusta programar y la informática en general. Me centro sobre todo en el backend y en diseñar APIs claras, pero también disfruto montar el frontend y ver cómo todo encaja.

Mi stack principal gira alrededor de **Java, Spring Boot, React y TypeScript**. Y como siempre hay algo nuevo que aprender, ahora mismo estoy explorando Ruby on Rails y Angular.

- ⚙️ Construyo apps Full-Stack con Spring Boot + React

- 🗄️ Trabajo con PostgreSQL y Supabase
- 📚 Mejoro un poco cada día

## 🚀 Proyecto actual

### Sistema de Gestión de Precios

Estoy desarrollando una aplicación Full-Stack orientada a la gestión y consulta de precios, integrando distintos servicios y APIs externas.

| Capa | Tecnología |
|---|---|
| Frontend | React · TypeScript |
| Backend | Java · Spring Boot |
| Base de datos | PostgreSQL · Supabase |
| Integraciones | REST APIs |
| Cloud | Azure |
| Entorno | Docker |

### Objetivos del proyecto

- Diseñar y mejorar la arquitectura backend
- Crear APIs REST limpias y bien estructuradas
- Modelar y persistir datos de forma eficiente
- Integrar múltiples servicios externos
- Gestionar autenticación y usuarios
- Aplicar containerización con Docker
- Desplegar soluciones en la nube
- Mantener un código organizado, escalable y mantenible
